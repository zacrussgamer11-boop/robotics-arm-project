Arduino UNO R4 WiFi robotics learning project.

## Current progress

- Learned breadboard basics
- Controlled an LED
- Used a pushbutton as input
- Read a potentiometer

- Added an LED movement indicator
- Added movement tolerance/deadband

## Current hardware

- Arduino UNO R4 WiFi
- Breadboard
- Potentiometer
- Servo motor
- LED
